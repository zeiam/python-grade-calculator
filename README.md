# Python Grade Calculator 🎓

A simple, interactive grade calculator built with Python. The program asks the user for their name and score, validates the score, and assigns a letter grade based on predefined grading criteria.

## ✨ Features

- Accepts student names and scores through user input.
- Validates scores to ensure they are between 0 and 100.
- Assigns letter grades based on the student's score.
- Displays the student's name, score, and final grade.

## 📊 Grading Criteria

| Score Range | Letter Grade |
|---|---|
| 90–100 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| Below 60 | F |

## 🛠️ Technologies Used

- Python 3
- Built-in `input()` and `int()` functions

## 🚀 How to Run

1. Make sure Python 3 is installed on your computer.
2. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

3. Navigate to the project folder:

   ```bash
   cd python-grade-calculator
   ```

4. Run the program:

   ```bash
   python grade_calculator.py
   ```
